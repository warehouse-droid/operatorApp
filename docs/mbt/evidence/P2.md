## Implemented verification behavior

- `record_by_id` permits only server-allowlisted Record REST types and encoded
  internal-ID GET paths with `Accept: application/json`.
- `metadata_catalog` permits only the configured `salesOrder` or
  `customerDeposit` parent schema at
  `/metadata-catalog/{encodedParentRecordType}` with
  `Accept: application/schema+json`, then projects one configured script ID.
- `derived_permission` issues no request and derives only from representative
  read evidence.
- `configured_unproven` issues no request and cannot prove or enable a future
  write permission.
- `unsupported` issues no request and remains `unable_to_verify`.
- Evidence evaluation has a hard concurrency ceiling of four and preserves
  immutable catalog order. Schema payloads are coalesced per parent record
  type for one adapter lifetime; separate script IDs remain separate bounded
  projections, and failed schema requests are evicted.
- Runtime fingerprint schema v3 binds the configured account, live runtime
  account, runtime environment, normalized `NETSUITE_REST_BASE_URL`,
  direct-access state, exact `MBT_NETSUITE_SANDBOX_ACCOUNT_ALLOWLIST`, read
  timeout, and effective preflight lease. Any change makes prior evidence
  stale; a production-like or mismatched account/host fails before an outbound
  request.
- Mapping configuration accepts only bounded `expected` evidence and unique
  `caseInsensitiveFields`; credential-like content, unrestricted keys, excess
  size/depth/node count, unsupported fields, and invalid scalar arrays are
  rejected. Server-owned expectations override configured conflicts.
- Customer, sale-item, and account evidence must prove membership in the
  current MBT subsidiary. Customer and sale-item mappings additionally require
  a dedicated subsidiary ID equal to the current MBT subsidiary mapping and
  cannot be saved before that mapping exists; accounts intentionally have no
  editable dedicated subsidiary field. Missing nullable customer evidence is
  distinct from an explicitly observed NetSuite `null`.
