MBBS Driver recovery

Hard reset this Driver site

This permanently deletes this browser's MBBS site data. Saved routes, unsynchronized actions, photos, login sessions, IndexedDB, service workers, and all MBBS caches on this site will be removed. Other MBBS modules opened in this browser will also be signed out.

Use this only while connected to the internet, after Reload and Repair have failed, and only when no offline evidence needs recovery.

Cancel and return to Driver

A website cannot erase Chrome's browsing-history list. This reset removes the site storage and caches that affect Driver login and application versions, and replaces this recovery page in the current tab.
