# Sales Order Re-load Regression Matrix

Run the persisted matrix from the repository root:

```bash
bash server/tools/sales-order-reload-gauntlet.sh
```

The gauntlet creates a fresh isolated PostgreSQL database, applies every migration, imports the five canonical Smart SCM regression sources through a read-only mount, and builds an isolated NetSuite item/balance mirror from those imports. This fixture includes one deterministic surplus source used by the legacy TO-planning coverage and one non-login Operator row required by the sync-shape delivery coverage; setup refuses to run outside `NODE_ENV=test` with `MBT_TEST_ISOLATED=1`. The gauntlet also builds the test and production-equivalent images and writes a timestamped log plus `latest.log` under `server/test-artifacts/sales-order-reload/`. It refuses to start if a required seed file is missing. Override the default `/home/ubuntu` seed directory with `SMART_SCM_REGRESSION_SEED_ROOT` when necessary.
