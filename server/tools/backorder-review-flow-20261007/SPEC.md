# Backorder stock-review and manual-link sequence

Spec approval: not obtained (autonomous run). Tier 3 for shared workflow/API and concurrency changes. The user requested these corrections and previously authorized deployment after passing tests.

Acceptance criteria, written before implementation:
1. A new Backorder or a partially reviewed Backorder rejects manual SO linking with HTTP 409/BACKORDER_STOCK_REVIEW_REQUIRED, leaves references/revision/events unchanged, and hides the Sales link form. Every open (not declined/closed) material needs a supply response and stock-check timestamp. All-closed or empty materials do not release a new SO.
2. After all open materials have SCM reviews, Sales can link an existing synced SO without material mappings, matching quantities, customer, vendor, yard or active/approved status comparisons. Sales acceptance is not a prerequisite.
3. SCM cannot link a PO before the persisted SO ID exists: HTTP 409/BACKORDER_SO_LINK_REQUIRED, no state changes, no PO form. The SO ref text alone is insufficient. After the SO link the PO form and API accept an existing synced PO without business comparisons.
4. Sales material changes invalidate the changed review and block an unlinked SO until SCM reviews it again. Stale and concurrent edits/links serialize on the request lock with revision errors; no partial links.
5. SCM material review contains no purchase-cost input and saves without a cost. Optional legacy/API costs remain compatible and private to SCM.
6. SCM Request information form and pending information/reply/header content appear before the Materials section.
7. Existing Special manual-link rules, Backorder SKU/UOM/vendor/yard routing, private notes, no generation/ancillaries, native previews, and completion requiring both links survive.

Failure model: gate bypass through raw API/shared repository (real HTTP/SQL), stale UI/request race (concurrent HTTP and locked transaction), loss of legacy data (state comparisons and unchanged schema), regressions in Special shared code (baseline/candidate affected suite), browser gate disagreement (actual Chromium plus ordering properties).
